4. Code example for dependency check:
```java
public class DependencyManager {
    private final JavaPlugin plugin;
    private boolean protocolLibAvailable = false;
    
    public DependencyManager(JavaPlugin plugin) {
        this.plugin = plugin;
        checkDependencies();
    }
    
    private void checkDependencies() {
        Plugin protocolLib = Bukkit.getPluginManager().getPlugin("ProtocolLib");
        if (protocolLib != null && protocolLib.isEnabled()) {
            protocolLibAvailable = true;
            plugin.getLogger().info("ProtocolLib found: " + protocolLib.getDescription().getVersion());
        } else {
            plugin.getLogger().warning("ProtocolLib not found or not enabled!");
            plugin.getLogger().warning("Advanced entity features will be disabled.");
            plugin.getLogger().warning("Install ProtocolLib: https://www.spigotmc.org/resources/protocollib.1997/");
        }
    }
    
    public boolean isProtocolLibAvailable() {
        return protocolLibAvailable;
    }
}
```

   - Add fallback message explaining limited functionality
   - Create alternative command implementation that works without ProtocolLib

6. Update plugin.yml:
