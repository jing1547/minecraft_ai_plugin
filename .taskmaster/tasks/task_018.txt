# Task ID: 18
# Title: Implement Villager-based AI Companion System
# Status: pending
# Dependencies: 16, 17, 15
# Priority: high
# Description: Replace the ProtocolLib-dependent FakePlayer system with a stable Villager NPC-based AI companion system that works reliably in Minecraft 1.21.6+ without compatibility issues.
# Details:
Implement a robust Villager-based AI companion system to replace the problematic FakePlayer implementation:

1. Create a new `VillagerCompanion` class:
   - Extend from `EntityVillager` or use Bukkit API to create and manage villager entities
   - Implement custom AI behaviors to follow players, respond to commands, and perform actions
   - Add metadata to identify these villagers as AI companions
   - Implement custom name tags and basic visual customization within Bukkit API limitations

2. Modify the existing companion architecture:
   - Create a common interface `AICompanion` that both `FakePlayerCompanion` and `VillagerCompanion` implement
   - Update `AICompanionManager` to support both companion types based on configuration
   - Add a configuration option `fake_player_mode: false` to switch between systems
   - Implement a factory pattern for creating the appropriate companion type

3. Implement core functionality for VillagerCompanion:
   - Following behavior (pathfinding to stay near player)
   - Command processing system
   - Persistence (saving/loading companion data)
   - Basic interaction capabilities
   - Combat support functionality
   - Inventory management (if applicable)

4. Create migration system:
   - Add functionality to convert existing FakePlayer companions to Villager companions
   - Preserve companion names, inventories, and other relevant data during conversion
   - Provide commands to manually trigger migration

5. Ensure backward compatibility:
   - Design the system to allow easy switching between implementations
   - Structure code to facilitate future upgrades when ProtocolLib compatibility improves
   - Document the limitations of the Villager-based system compared to FakePlayer

6. Update user interface:
   - Modify command feedback to reflect the current companion type
   - Update help documentation to explain the different modes
   - Add visual indicators to distinguish AI companions from regular villagers

# Test Strategy:
1. Test basic Villager companion functionality:
   - Verify spawning works correctly in Minecraft 1.21.6+
   - Confirm companions are visible to all players
   - Test following behavior at various distances and through different terrain
   - Verify companions respond to all commands correctly

2. Test persistence and data management:
   - Create and customize multiple companions
   - Restart the server and verify all companions load correctly
   - Test companion data saving during server crashes
   - Verify companion state is maintained correctly

3. Test configuration switching:
   - Switch between FakePlayer and Villager modes via config
   - Verify existing companions are properly migrated
   - Test performance impact of both implementations

4. Compatibility testing:
   - Test on multiple Minecraft versions (1.21.6, 1.21.7, etc.)
   - Verify functionality with and without ProtocolLib installed
   - Test with various server configurations (Paper, Spigot, etc.)
   - Check for conflicts with other plugins that modify villagers

5. Performance testing:
   - Measure server impact with multiple companions active
   - Test with high player counts to ensure stability
   - Verify memory usage remains within acceptable limits
   - Check for any tick rate impacts during companion actions

6. User experience testing:
   - Gather feedback on the visual appearance and behavior
   - Test with different permission levels
   - Verify all commands work as expected with the new implementation
